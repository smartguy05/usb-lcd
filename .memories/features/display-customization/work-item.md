# Display customization

Add four-way mounting orientation, an inactivity screen saver, and managed
background-image uploads through the settings editor.

## Acceptance criteria

- Landscape, portrait, and both flipped mountings render upright on supported panels.
- Orientation changes in the editor rotate the existing layout safely.
- An enabled-by-default moving clock appears after 10 minutes without dashboard activity and wakes on activity.
- PNG, JPEG, and WebP wallpapers can be uploaded and appear behind translucent cards.
- Existing configurations and the no-wallpaper legacy pixel baseline remain compatible.
- Tests, documentation, release metadata, and both installers are current.
