# Human todo list

Implement one global personal todo list shared by the LCD, admin site, Claude Code, and Codex. Items are human actions only, never agent scratch work.

## Acceptance criteria

- Persistent open/completed todos with title, details, priority, date-only deadline, manual order, and timestamps.
- Responsive LCD widget with prioritized rotating pages.
- Full admin CRUD, history, reopen, reorder, and confirmed deletion.
- User-scoped Claude/Codex MCP tools with human-only usage instructions.
- Existing layouts remain unchanged; installers, docs, hashes, and packages are current.
